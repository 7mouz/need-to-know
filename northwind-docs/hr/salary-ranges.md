# Salary Ranges by Job Level (2026)

> Fictional demo data. All numbers are invented.

**People team only.** Ranges are reviewed every July. Yearly base pay in US dollars.

| Job level | Range |
|---|---|
| Support Specialist I | $52,000 – $64,000 |
| Support Specialist II | $62,000 – $76,000 |
| Support Lead | $78,000 – $95,000 |
| Software Engineer I | $105,000 – $125,000 |
| Software Engineer II | $122,000 – $148,000 |
| Senior Software Engineer | $150,000 – $185,000 |
| Staff Software Engineer | $180,000 – $220,000 |
| Product Manager | $130,000 – $165,000 |
| IT Support Technician | $58,000 – $72,000 |

## How we use these ranges

- New offers usually land in the lower half of the range.
- Moving up a level means moving to that level's range.
